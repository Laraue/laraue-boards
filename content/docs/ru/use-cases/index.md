Каждое руководство в этом разделе начинается с цели и шаг за шагом ведёт к ней, а за подробностями отсылает к справочным страницам.

## В этом разделе

- [Групповой чат Telegram как доска задач команды](/ru/documentation/use-cases/telegram-group-chat-task-board) — привяжите групповой чат к общей доске и командой `/save` превращайте любое сообщение в карточку, которую видит вся команда.

- [Сохраняйте ссылки и идеи из Telegram](/ru/documentation/use-cases/save-links-and-ideas-from-telegram) — пересылайте боту ссылки, заметки и фото, чтобы они попадали на доску с поиском, а не терялись в «Избранном».

- [Бэклог для разработки с ИИ: Claude Code и Cursor](/ru/documentation/use-cases/ai-agent-backlog) — пусть ИИ-агент для разработки читает ваш бэклог, заводит баги и переносит issues по ходу работы.

- [Передайте issues ИИ-агенту и проверяйте его работу](/ru/documentation/use-cases/delegate-issues-to-ai-agent) — передавайте понятные issues Claude Code или Codex на вашем компьютере, проверяйте результат там, где работаете, и просите доработку командой `lba continue`.
