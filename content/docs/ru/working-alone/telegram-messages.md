В основе Laraue Boards простая мысль: работа и так уже идёт в Telegram. Просьба клиента, сообщение об ошибке, фото того, что нужно починить, — всё это issues, просто пока не разложенные по местам. Laraue Boards сохраняет их сразу из Telegram.

## Пересылка сообщения боту

Самый простой способ сохранить сообщение:

1. Зажмите любое сообщение в любом чате Telegram
2. Нажмите **Переслать**
3. Выберите **@msgboard_bot**
4. Сообщение сразу станет issue на вашей доске по умолчанию

![Пересланное сообщение в Telegram и реакция бота: сообщение сохранено](https://laraue.com/static/images/blog/docs/laraue-boards/message-board-bot-processed-message.jpg)

Так можно сохранить текст, фото, видео, документы и альбомы.

## Что сохраняется

Из пересланного сообщения Laraue Boards сохраняет:

- **Текст** сообщения (до 4096 символов)
- **Фото** и **видео** — миниатюрами на странице issue; при открытии они загружаются из Telegram в исходном качестве
- **Документы** — PDF, Word (DOCX, DOC), Markdown, TXT и JSON, а также изображения, отправленные файлом; они прикрепляются к issue, и их можно скачать (форматы и ограничения — в статье [Вложения](/ru/documentation/features/media#что-можно-прикрепить))
- **Имя отправителя** — его вместе со временем видно в карточке issue, которую бот присылает в Telegram (`/save`, `/info`, inline-поиск)
- **Время** отправки исходного сообщения

Не сохраняются реакции, ответы, сведения о том, откуда переслано сообщение, расшифровки голосовых сообщений и файлы других типов.

## Файлы, которые не сохраняются

Документ неподдерживаемого типа (архив, таблица, исполняемый файл…) или больше допустимого размера пропускается. Остальное — текст и поддерживаемые вложения — всё равно сохраняется, а бот сообщает, какой файл не сохранён и почему:

- **`/save` и `/aisave`** всегда называют пропущенные файлы в ответе.
- В чате, где **сохраняется каждое сообщение**, бот отвечает, только если пропущенный файл был единственным содержимым сообщения, — тогда issue не создаётся. Если в сообщении был ещё текст или другие вложения, issue молча сохраняется без файла.
- **Правки** никогда не вызывают сообщений бота: если документ заменили неподдерживаемым, он тихо убирается из issue.

## Вложения в issue

На карточке доски миниатюр нет — медиа видно, только когда вы открываете issue. На странице issue под описанием есть блок вложений, где каждое фото и видео показано маленькой миниатюрой. Нажмите на миниатюру, чтобы открыть полное изображение.

![Блок вложений на странице issue](https://laraue.com/static/images/blog/docs/laraue-boards/issue-attachments.jpg)

Там же можно добавить свои изображения — кнопкой **Прикрепить файлы** (скрепка) или вставив картинку через **Ctrl+V** — и удалить любое вложение крестиком на миниатюре.

## Откуда пришёл issue

У issue из Telegram на боковой панели страницы, рядом с датой создания, есть строка **Создана через**: значок Telegram и название чата, из которого пришло сообщение.

Если Telegram может открыть сообщение, в конце строки есть значок ссылки (↗), который его открывает. Будет ли она, зависит от чата:

- **Публичная группа** (у неё есть @username) — ссылка открывает сообщение для всех.
- **Закрытая группа** — ссылка открывает сообщение только участникам группы; остальным Telegram покажет ошибку.
- **Небольшая группа** (обычная группа, ещё не ставшая супергруппой) — ссылки нет: у сообщений в таких группах в Telegram нет ссылок.
- **Ваш личный чат с ботом**, в том числе пересланные ему сообщения, — в строке написано **личный чат с ботом**, без ссылки.

Строку и ссылку видят все, кто видит issue: Boards не может проверить, состоите ли вы в чате.

Когда Telegram превращает обычную группу в супергруппу (например, когда у группы появляется @username или много участников), сообщения нумеруются заново. У issues, сохранённых до этого, строка **Создана через** остаётся, но без ссылки; у сохранённых после — ссылка есть, как обычно.

## Issues без текста

Чтобы стать issue, сообщению не обязательно содержать текст. Фото без подписи станет issue только с медиа: на странице issue будут миниатюры и пустое описание, а заголовок соберётся из типа медиа, времени и названия чата — например, `image-20260930-101500-Название чата`. Документ без подписи получит заголовок по имени файла — например, `contract.pdf`.

## Issues, созданные вручную

Issues, созданные кнопкой **Добавить задачу**, не связаны ни с каким сообщением Telegram. У них те же поля (описание, статус, атрибуты), но нет отправителя и медиа из Telegram, а в строке **Создана через** указано веб-приложение.
