Ваша команда уже работает в Telegram: там принимают решения, ставят задачи и пересылают файлы. Laraue Boards встраивается в этот процесс: сообщения, которые вы и так отправляете, становятся issues на канбан-доске. Общаться по-другому не придётся.

![Канбан-доска в Laraue Boards с issues, разложенными по статусам](https://laraue.com/static/images/blog/docs/laraue-boards/board-example.jpg)

## Что такое Laraue Boards

Laraue Boards — инструмент для управления проектами, в основе которого одно наблюдение: **задача появляется в тот момент, когда кто-то отправляет сообщение**. Остаётся только навести в задачах порядок.

- Откройте его как **Telegram Mini App** — без отдельного входа и нового аккаунта
- Или работайте в полноценном **веб-приложении** на [boards.laraue.com](https://boards.laraue.com)
- Отправьте боту сообщение — текст, фото, видео или альбом, — и оно само станет issue
- Отредактируйте сообщение в Telegram — issue обновится вместе с ним
- Раскладывайте issues по **эпикам** (доскам) с настраиваемыми колонками статусов
- Объединяйте эпики в **пространства** — по проектам или по клиентам
- Добавляйте issues **атрибуты** — собственные поля под ваш процесс
- Работайте командой в **организациях**, где права доступа настраиваются для каждой операции

![Настройка прав доступа в Laraue Boards](https://laraue.com/static/images/blog/docs/laraue-boards/permissions-setup-example.jpg)

## Основные понятия

| Понятие          | Что это                                                                                                                          |
|------------------|----------------------------------------------------------------------------------------------------------------------------------|
| **Issue**        | Единица работы: сообщение, сохранённое из Telegram, или задача, созданная вручную. У каждого issue есть номер в пределах пространства, например `WRK-42` |
| **Эпик (Epic)**  | Доска с колонками статусов — ваш канбан                                                                                          |
| **Пространство (Space)** | Группа связанных эпиков, например проект или клиент                                                                             |
| **Организация**  | Общее место работы команды, где у каждого участника свои права доступа                                                 |
| **Бэклог (Backlog)** | Эпик по умолчанию: сюда попадают issues, пока вы не разложите их по своим доскам                                             |
| **Атрибут**      | Собственное поле issue — например, тип или приоритет. Атрибуты настраивает администратор                                         |

## Для кого

**Для одного человека** — личный органайзер задач. Сообщения в Telegram становятся бэклогом, доски — вашим рабочим процессом. Команда не нужна.

**Для небольших команд** — создайте организацию, пригласите коллег по ссылке и работайте на общих досках. Особенно удобно командам в СНГ, где Telegram — основной канал деловой переписки.

**Для агентств** — разделите работу с клиентами по пространствам и отслеживайте, что обсуждали и что уже сделано. Покупать отдельный PM-инструмент под каждого клиента не нужно.
