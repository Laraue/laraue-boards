В Laraue Boards искать можно на каждой доске, в Бэклоге и на странице со всеми issues организации.

## Поиск на доске

Нажмите значок поиска в шапке доски. Откроется поле поиска, и по мере ввода во всех колонках останутся только карточки, у которых заголовок или описание подходят под запрос.

Чтобы закрыть поиск, нажмите Escape или ещё раз на значок. Когда вы переходите на другую доску, поиск сбрасывается.

## Поиск в Бэклоге

В шапке Бэклога такое же поле поиска: список issues фильтруется по мере ввода.

## Поиск по всей организации

Пункт **Все задачи** в боковой панели — над списком пространств — показывает все issues организации сразу, на каком бы пространстве или доске они ни лежали. В каждой строке указаны пространство и доска issue, так что видно, где он находится.

![Страница «Все задачи»: issues из всех пространств, поле поиска и кнопка фильтров](https://laraue.com/static/images/blog/docs/laraue-boards/all-issues.jpg)

На этой странице есть своё поле поиска и кнопка фильтров, чтобы сузить список: по атрибуту, по пространству или по **статусу доски** — только issues с досок в статусе «Новая», «В работе» или «Готово» (см. [Статус доски](/ru/documentation/concepts/epics)).

## Поиск вместе с фильтрами

Поиск на доске работает вместе с фильтрами по атрибутам: можно искать по тексту и одновременно фильтровать по атрибуту. Доска покажет только issues, которые подходят и под запрос, и под выбранные фильтры.
