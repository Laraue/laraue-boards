Каждый issue получает уникальный номер — короткий идентификатор вида `WRK-42` или `MOB-7`. По номеру можно сослаться на конкретный issue в переписке или поделиться прямой ссылкой на него.

## Как появляется номер

Номер состоит из двух частей: трёх букв из названия **пространства** и порядкового номера внутри этого пространства. `WRK-1`, `WRK-2`, `MOB-14` — нумерация ведётся по пространству, а не по отдельной доске в нём.

У эпика (доски) собственного номера нет — у него только внутренний id.

## Когда номер меняется

При переносе issue на другую доску **того же пространства** номер не меняется. При переносе в **другое пространство** issue получает новый номер, потому что нумерация ведётся по пространству. Ссылки и номера этого issue, которыми уже поделились, будут указывать на старый номер и перестанут работать.

## Номера в Telegram

Напишите номер в любом сообщении Telegram — «см. WRK-42» — и всем, у кого есть доступ, сразу понятно, о каком issue речь.

## Прямая ссылка на issue

У каждого issue есть и прямая ссылка:

```
https://boards.laraue.com/organizations/{OrgKey}/issues/{IssueKey}
```

Рядом с номером на странице issue есть значок ссылки — нажмите его, чтобы скопировать ссылку, а не набирать её вручную.

![Значок ссылки рядом с номером issue: по нему копируется прямая ссылка](https://laraue.com/static/images/blog/docs/laraue-boards/copy-issue-link.jpg)

## Где виден номер

- В строке issue в Бэклоге и в списках
- На странице issue, рядом с заголовком, вместе со значком копирования ссылки
