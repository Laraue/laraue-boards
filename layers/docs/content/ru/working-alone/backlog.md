Бэклог — доска, с которой начинается каждое пространство. Все issues, которые вы сохраняете из Telegram, попадают в Бэклог.

## Что в Бэклоге

Бэклог — это список issues, которые ещё не разложены по статусам. Он показывает их так же, как любая другая доска, только без колонок. В каждой строке — номер issue, его текст и исполнитель.

![Бэклог со списком issues](https://laraue.com/static/images/blog/docs/laraue-boards/backlog-view.jpg)

## Поиск в Бэклоге

Нажмите значок поиска в шапке Бэклога: список фильтруется по мере ввода. Чтобы очистить поиск, нажмите Escape или ещё раз на значок.

## Перенос issue из Бэклога

Справа в каждой строке есть значок переноса — нажмите его, чтобы перенести issue на другую доску прямо из списка, не открывая issue.

Можно и открыть issue и выбрать другую доску или пространство на его странице — как на любой другой доске.
